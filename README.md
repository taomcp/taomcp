# Yao Tao

Building FPGA, MATLAB, and AI agent tooling.

I work on practical local workflows that let AI do more of the real engineering loop:

- MATLAB-based validation with lower token cost and less setup friction
- Vivado integration for edit, simulation, synthesis, implementation review, bitstream, and debug workflows
- AI-agent tooling for reproducible local automation

## Featured Repositories

### [matlab-mcp](https://github.com/taomcp/matlab-mcp)

A file-based MATLAB bridge for AI agents that cuts token usage and speeds up figure and data validation.

- MATLAB R2016a+ only
- no Python runtime required
- no background server
- easy to inspect, easy to adapt

### [vivado-mcp-integration-kit](https://github.com/taomcp/vivado-mcp-integration-kit)

An integration-ready Vivado MCP toolkit for AI agents, focused on practical local workflows across editing, faster simulation, synthesis, implementation analysis, bitstream generation, and ILA-oriented debug.

- built for end-to-end local FPGA workflows
- helps reduce manual handoff between build stages
- organized for AI-driven automation instead of one-off scripts
